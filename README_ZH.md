# ChronoGraph

一款基于 SwiftUI 的 iOS 日历隐私分享工具。选择日历、日期范围和可见性规则后，可以生成长图，也可以维护独立的 iCloud 日历供他人订阅。

> English version: see [README.md](README.md)

## 核心特性
- **日期范围**：今天 / 未来 3 天 / 7 天 / 14 天 / 自定义范围。
- **多日历选择**：首次默认全选；后续选择持久化存储。
- **隐私模式**：隐藏（忙闲与时间）/ 缩略（标题与时间）/ 完整（标题、时间、地点、备注）；共享日历在写入副本前移除未被允许的字段。
- **共享 iCloud 日历**：支持多份独立配置，每份有自己的来源、滚动或固定范围、默认可见性，以及单次或重复系列的覆盖规则，支持“不分享”。
- **忙碌状态可视化**：基于 `EKEventAvailability`（忙碌 / 空闲 / 暂定 / 不可用），彩色圆点 + 标签。
- **折叠空白日期**：仅保留日期头部，减少长图高度。
- **确定性长图导出**：锁定宽度再渲染，避免布局抖动；自适应安全缩放；统一背景避免透明；支持 Light / Dark 一致性。
- **系统分享**：生成后直接弹出 `UIActivityViewController`（AirDrop / 微信 / 文件 / 备忘录 等）。
- **双渲染路径**：优先使用 iOS 16+ `ImageRenderer`，失败回退 UIKit Snapshot，降低空白图风险。
- **状态持久化**：隐私模式 / 日期范围 / 已选日历 ID / 折叠偏好 等。
- **日历授权**：申请完整日历访问权限，读取预览，并维护用户明确启用的输出日历。

## 共享日历

创建共享配置，选择来源日历和 iCloud 目标账户，检查脱敏后的预览，再启用维护。每份配置使用独立的专用输出日历，不修改来源事件。所有应用生成的日历都从来源列表中排除，避免循环复制。

可见性优先级为：单次覆盖 > 系列覆盖 > 共享配置默认值。“不分享”不生成副本；“隐藏”保留起止时间、全天标记、忙闲状态和忙闲占位标题；“缩略”增加原始标题；“完整”再增加地点和备注。不复制参会者、组织者、提醒、附件或原始 URL。输出事件带有包含随机标识的不透明标记 URL，用于同步恢复，不包含原始来源标识或日程文字。

创建时，应用在目标日历名称中使用临时随机标记，以恢复 EventKit 写入与本地存储之间的中断，随后改回友好名称；不会仅凭普通日历重名而绑定。如果用户手动给输出事件加入参会者或组织者，同步会因这些 EventKit 只读字段而停止并提示修复，应用无法声称已将其移除。

本机更新完成后，在系统日历中找到这份 iCloud 专用日历，开启“公开日历”并复制订阅链接，或邀请指定 iCloud 用户。EventKit 没有公开日历或获取公开链接的接口，ChronoGraph 提供操作指引。参见 [Apple 日历共享说明](https://support.apple.com/zh-cn/guide/iphone/iph7613c4fb/ios)。

首版由一台设备维护共享配置。打开应用、运行期间的来源变动及系统允许的后台刷新会触发更新；iOS 后台执行和订阅方刷新都不保证固定频率。本机写入成功不代表 iCloud 已上传或订阅方已刷新。滚动范围在下次成功更新时推进，固定范围保持所选日期。

共享配置、覆盖规则、身份映射和写入意图使用专用本地 SwiftData 目录，并排除设备备份；不会随设备迁移恢复，也不在不同安装之间同步。重装应用或更换设备后，已有输出日历仍可能留在 iCloud，需要通过系统日历管理共享。若原目标账户不可用，应用保留配置并阻止删除或重建，直到能够核查该账户。

“暂停更新”会保留已有输出和共享。停止共享需要到系统日历中关闭访问。删除配置对应的专用日历需确认，会删除其中全部内容，包括手动加入的日程。撤销日历权限不会清除已有 iCloud 副本，已经下载的内容也无法追回。请勿向应用维护的专用日历手动添加日程。

## 目录结构概览
```
ChronoGraph/
  Managers/
    CalendarManager.swift        // 授权、日历 & 事件抓取、偏好持久化
    ImageExportManager.swift     // SwiftUI 视图转 UIImage（长内容安全缩放）
    ExportedImageItemSource.swift// 分享表单富元数据 (临时 JPEG 文件)
  Models/
    CalendarEvent.swift          // EKEvent 投影 + 忙碌状态 + 隐私枚举
  Views/
    InAppEventListView.swift     // 日期分组列表 + 隐私遮罩 + 详情弹窗
    CalendarSelectionView.swift  // 日历过滤选择
    ContentView.swift            // 主容器/工具栏/导出入口
  ChronoGraphApp.swift           // App 入口
```
架构风格：轻量 MVVM。*Managers* 持有状态与副作用；*Views* 纯渲染 + 用户交互；*Models* 隔离外部框架类型（EventKit）。

## 导出流程（高层）
1. 用户点击分享按钮。
2. 创建一个“等宽 / 等参数”的镜像列表视图（避免直接引用滚动中视图造成高度不稳定）。
3. `ImageExportManager.generateImage` 预计算目标高度，选择安全缩放（最长边 ≤ 16384px）。
4. 生成 UIImage，封装为 `ExportedImageItemSource`（附标题 / 图片 / 临时文件 URL）。
5. 弹出系统分享面板。

## 隐私模式说明
| 模式 | 用户看到 | 数据暴露风险 |
|------|----------|--------------|
| 隐藏 | 仅忙碌块（用状态名代替标题） | 极低 |
| 缩略 | 标题 + 起止时间 | 低 |
| 完整 | 标题 / 时间 / 位置 / 备注 | 取决于内容 |

> 图片在本地生成，由用户决定是否分享。明确启用共享日历后，应用把允许的输出字段写入用户选择的 iCloud 日历，由 Apple 同步。本地只保存偏好、共享配置、覆盖、状态和身份映射，不额外持久化完整来源日程数据库。详见[隐私政策](隐私政策.md)。

## 运行要求
- **iOS**：17.0+；共享功能需要启用 iCloud 日历。
- **Xcode**：需支持工程使用的同步文件组与应用图标资源；权限和工程配置使用 Xcode 27 检查。
- **依赖框架**：SwiftUI / EventKit / UIKit / SafariServices / BackgroundTasks。

### 权限描述 (Info.plist)
Debug 和 Release 均将 `Config/ChronoGraph-Info.plist` 与生成的应用元数据合并，包含 `NSCalendarsFullAccessUsageDescription` 和兼容键 `NSCalendarsUsageDescription`，说明预览、图片与主动启用后的脱敏 iCloud 写入。源 plist 提供 `UIBackgroundModes = [fetch]` 和 `BGTaskSchedulerPermittedIdentifiers = [com.shiyao-zhang.ChronoGraph.shared-calendar-refresh]`，任务标识必须与应用注册一致。

## 快速开始
1. 克隆仓库。
2. 打开 `ChronoGraph.xcodeproj`。
3. 在目标设置里配置 Team（签名）；应用通过 EventKit 使用设备已有的 iCloud 账户，不使用 CloudKit 容器。
4. 选择真机 / 模拟器运行，首次访问会弹授权框。
5. 选择日历 → 切换隐私模式 → 点击导出按钮。

## 错误与安全处理
- 事件抓取使用 UUID Token 避免竞态（后发覆盖先发）。
- 渲染尺寸上限防止 CoreGraphics 内存/尺寸崩溃。
- 双路径渲染降低空白图风险。
- 失败不强制自动分享（需非空图像）。
