# ChronoGraph

一款基于 SwiftUI 的 iOS 日历隐私分享工具。选择日历、日期范围和可见性规则后，可以生成长图，也可以维护独立的 iCloud 日历供他人订阅。

新增可选的**云端协作测试入口**（设置 → 云端协作）：通过邀请码注册和账号密码登录（或可选的 Apple 登录）、单独同意后上传所选日历的忙闲或允许详情，添加其他账号分享的来源，查找共同时间并发起、回应和定档邀约。云端与现有本机浏览、图片导出及 iCloud 共享独立；后者的“不分享”规则不会自动套用于另行选择的云端上传来源。部署、授权与当前限制见 [后端说明](backend/README.md)。

> English version: see [README.md](README.md)

## 核心特性
- **日期范围**：个人与共享视图使用统一控件：今天 / 未来 3 天 / 7 天 / 14 天 / 自定义滚动或固定日期；快捷项是包含今天的滚动范围。
- **多日历选择**：首次默认和“全选”均排除应用生成的日历；个人查看可手动选择共享副本，后续保留选择。
- **内容层级**：仅忙闲 / 标题与时间 / 标题、地点与备注；本机显示、对外共享与云端上传分别设置，共享日历在写入副本前移除未被允许的字段。
- **共享 iCloud 日历**：支持多份独立配置，每份有自己的来源、滚动或固定范围、默认可见性，以及单次或重复系列的覆盖规则，支持“不分享”。
- **忙碌状态可视化**：基于 `EKEventAvailability`（忙碌 / 空闲 / 暂定 / 不可用），彩色圆点 + 标签。
- **折叠空白日期**：仅保留日期头部，减少长图高度。
- **确定性长图导出**：锁定宽度再渲染，避免布局抖动；自适应安全缩放；统一背景避免透明；支持 Light / Dark 一致性。
- **系统分享**：视图、可见性、日期和分享沿用相同的工具栏菜单样式；分享只提供图片与日历链接，修改共享规则从主页状态行进入。图片先预览，由用户点击发送后打开系统分享面板（AirDrop / 微信 / 文件 / 备忘录 等）。
- **双渲染路径**：优先使用 iOS 16+ `ImageRenderer`，失败回退 UIKit Snapshot，降低空白图风险。
- **状态持久化**：隐私、日期、来源和折叠偏好，以及每份共享日历的本机查看设置与未确认草稿，独立于已确认的共享规则保存。
- **日历授权**：申请完整日历访问权限，读取预览，并维护用户明确启用的输出日历。

## 界面入口

主界面保留日程列表与底部四个菜单：本机显示内容、日期、视图、分享。“视图 → 选择显示的日历”始终调整当前视图，不切换到其他日程场景，也不修改共享规则；日程总览可混合显示本机日历、自己上传的云端共享副本与别人分享的云端日历。每份共享视图的状态行用于编辑或审阅共享规则。有未来的待回应邀约，或参与者均已同意、等待自己定档的邀约时，顶栏显示待处理数量并可直达详情；进入前台、下拉和打开收件箱独立刷新邀约，不依赖上传或其节流。刷新失败会保留缓存并提供重试。

主页“视图”菜单只保留视图切换与显示来源选择，新建统一从“分享 → 共享日历”进入。日程总览的“选择显示的日历”优先显示 ChronoGraph 云端，区分“我共享的”与按分享者分组的“我接收的”；其后按实际账号标识排列其他日历服务，标注应用维护的共享副本、订阅日历及只读日历。同名账号仍分别显示；系统属性无法可靠判断是谁分享的，所属服务的订阅与共享关系仍在该服务或系统日历中管理。自己的云端副本按服务器已共享的内容读取，不会自动与本机原日历一起勾选。加载与读取失败有明确状态，支持重试和下拉刷新。

收到的云端日历可以在显示选择中侧滑／长按，或从“收到的日历”页面取消订阅。确认后只移除自己的接收权限与显示选择，来源、其他接收者和独立公开订阅不受影响；失败保留订阅供重试。原一次性添加链接仍保持已使用，重新接收需对方提供新的有效链接。取消订阅保留既有邀约历史和已保存到系统日历的约定。

“分享 → 共享日历”统一展示按日历账号、ChronoGraph 云端区分的已配置日历，以及两种新建渠道。已选中某份 iCloud 共享日历时仍可直接发送其订阅链接，“其他共享方式”才进入统一入口。两条渠道共用来源行、日期控件、内容选项、范围摘要及单次／系列规则控件；各自的来源资格、权限确认及访问管理保持明确。

一份具名云端共享配置可合并多个本机日历，统一生成共享日历和链接；同一个来源日历也可加入不同配置，分别设置规则。选择日期与默认内容后，可预览日程，对单次或整个重复系列设置“不分享／仅忙闲／标题与时间／标题、地点与备注”，或恢复继承系列／配置默认值。规则只调整这份共享的输出，不修改原日程。“不分享”的事项不会上传，也不参与对方通过此配置查找共同时间。最终审阅实际共享内容并同意传输后才发布；所有来源均读取成功后才能替换云端快照。

设置分为显示偏好、共享与协作管理、应用信息。“我分享的日历”集中管理 iCloud 输出、来源和目标、更新状态及共享规则。云端协作优先展示找时间与邀约，并将上传日历、收到的日历、账号与服务器分别放入管理页面；显示来源选择页可直接进入收到日历的管理页面。

在原上传设备中，可独立审阅并确认修改配置名称、来源、日期与日程规则，或暂停／恢复此设备上传。云端与 iCloud 共用滚动／固定日期控件，云端范围最多180天；旧配置保留原有单日历、内容级别及过去7天至未来90天的日期范围。服务器字段上限由默认内容与单独规则共同决定；降低上限会清理服务器已有的超出字段并收紧链接与授权，以后增加字段不会自动扩大已收紧的授权。每个日程的返回内容还会受到自身规则和接收方权限限制。暂停保留云端数据与访问权限，仍会刷新收到的日历、邀约及已保存约定状态。修改失败时保留完整待完成配置，并在完成前阻止创建新链接；未完成的新建会用原来源标识继续。已有访问仍需单独管理。找时间使用自己的全部云端来源及所选参与者的已授权来源，与首页显示勾选独立。

## 共享日历

创建共享草稿，选择来源日历和 iCloud 目标账户，审阅目标、日期、可见性及预计日程变化，主动打开默认关闭的数据传输同意开关，再最终确认后才创建。后续规则修改同样经过“草稿 → 审阅 → 确认”；保留或放弃草稿都不会发布。每份配置使用独立的专用输出日历，不修改来源事件。应用生成的日历不能成为共享来源，避免循环复制。

**确认后会发生设备外的数据传输**：允许的日程字段通过系统日历写入所选目标账户，再由其服务提供商同步（iCloud 由 Apple 处理）。即使来源只在本机或属于其他账户，也会产生目标账户中的副本；来源的访问权限不会随副本保留。系统接口不能可靠区分 iCloud 和其他 CalDAV 账户，须核对实际目标。公开订阅链接的任何持有者都可读取日历并转发链接；导入链接本身不会更改系统共享权限。

主页工具栏调整本机查看的日期、来源和详情可见性，不发布，也不修改已确认的共享规则；个人设置与每份共享日历的查看设置分别保留。点击主页状态行即可修改共享：当前日期或来源有差异时，将这两项作为候选直接进入审阅，最终确认后才生效，不会导入本机“标题、地点与备注”显示选项；日期和来源无差异时，进入共享编辑器。若已有未确认草稿，先选择将当前日期与来源合并后审阅全部修改、继续编辑原草稿，或取消并保留草稿。事件详情默认只读，修改共享可见性也须审阅确认；超出已确认日期或来源的日程，不会因为选择“标题、地点与备注”就自动纳入共享。

可见性优先级为：单次覆盖 > 系列覆盖 > 共享配置默认值。“不分享”不生成副本；“仅忙闲”保留起止时间、时区信息（如有）、全天标记、忙闲状态和忙闲占位标题；“标题与时间”增加原始标题；“标题、地点与备注”再增加地点和备注，包括主页或图片未显示的备注。不复制参会者、组织者、提醒、附件或原始 URL。输出事件带有包含随机标识的不透明标记 URL，用于同步恢复，不包含原始来源标识或日程文字。

创建时，应用在目标日历名称中使用临时随机标记，以恢复 EventKit 写入与本地存储之间的中断，随后改回友好名称；不会仅凭普通日历重名而绑定。如果用户手动给输出事件加入参会者或组织者，同步会因这些 EventKit 只读字段而停止并提示修复，应用无法声称已将其移除。

共享视图的图片预览默认使用“已确认的共享内容”；如主动选择“当前视图”，会显示其中尚未共享的事件数量。生成或发送图片不会修改订阅规则。在系统分享面板选择“存储图像”可保存到“照片”，仅请求添加照片的权限，不读取照片图库。

本机更新完成后，在系统日历中找到这份 iCloud 专用日历，开启“公开日历”并复制订阅链接，或邀请指定 iCloud 用户。将订阅链接首次导入 ChronoGraph 并保存到对应日历后，后续可以直接发送已保存的链接，不必每次回到系统日历。链接仅保存在本机，发送时由用户选择的系统分享目标处理。需要替换时选择“更换链接”；取消更换会恢复原已保存地址。只有用户主动粘贴时才读取剪贴板。应用不验证所填链接是否公开或对应当前日历；重建目标后须重新保存链接。EventKit 没有公开日历或获取公开链接的接口，ChronoGraph 提供操作指引。参见 [Apple 日历共享说明](https://support.apple.com/zh-cn/guide/iphone/iph7613c4fb/ios)。

首版由一台设备维护共享配置。打开应用、运行期间的来源变动及系统允许的后台刷新会触发更新；iOS 后台执行和订阅方刷新都不保证固定频率。本机写入成功不代表 iCloud 已上传或订阅方已刷新。滚动范围在下次成功更新时推进，固定范围保持所选日期。已确认规则也适用于随后新增或修改的来源日程，无需逐条重新确认；未确认草稿不会参与更新。

已确认的共享配置、覆盖规则、身份映射和写入意图使用专用本地 SwiftData 目录，并排除设备备份；不会随设备迁移恢复，也不在不同安装之间同步。偏好、本机查看设置及未确认草稿另存于系统偏好存储，可能随系统备份或迁移保留，但不能恢复对已有输出日历的维护。重装应用或更换设备后，已有输出日历仍可能留在 iCloud，需要通过系统日历管理共享。若原目标账户不可用，应用保留配置并阻止删除或重建，直到能够核查该账户。

“暂停更新”会保留已有输出和共享；恢复前会再次提醒目标账户及数据传输，并要求确认。停止共享需要到系统日历中关闭访问。删除配置对应的专用日历需确认，会删除其中全部内容，包括手动加入的日程。撤销日历权限不会清除已有 iCloud 副本，已经下载的内容也无法追回。请勿向应用维护的专用日历手动添加日程。

## 目录结构概览
```
ChronoGraph/
  Managers/
    CalendarManager.swift        // 授权、日历 & 事件抓取、偏好持久化
    ImageExportManager.swift     // SwiftUI 视图转 UIImage（长内容安全缩放）
    ExportedImageItemSource.swift// 分享表单富元数据 (临时 JPEG 文件)
  Models/
    CalendarEvent.swift          // EKEvent 投影 + 忙碌状态 + 隐私枚举
  Views/
    InAppEventListView.swift     // 日期分组列表 + 隐私遮罩 + 详情弹窗
    CalendarSelectionView.swift  // 日历过滤选择
    ContentView.swift            // 主容器/工具栏/导出入口
  ChronoGraphApp.swift           // App 入口
```
架构风格：轻量 MVVM。*Managers* 持有状态与副作用；*Views* 纯渲染 + 用户交互；*Models* 隔离外部框架类型（EventKit）。

## 导出流程（高层）
1. 点击分享并选择“分享图片”；共享图片默认使用已确认内容，当前视图须主动选择。
2. 按所选图片范围创建等宽列表，避免直接引用滚动中视图造成高度不稳定。
3. `ImageExportManager.generateImage` 预计算目标高度，选择安全缩放（最长边 ≤ 16384px）并生成预览。
4. 检查图片后点击“发送图片”。
5. 由 `ExportedImageItemSource` 提供临时 JPEG 与元数据，打开系统分享面板。

## 隐私模式说明
| 模式 | 用户看到 | 隐私暴露内容 |
|------|----------|--------------|
| 仅忙闲 | 仅忙碌块（用状态名代替标题） | 仍可推断具体时间和忙闲规律 |
| 标题与时间 | 标题 + 起止时间 | 标题可能包含个人信息或会议链接 |
| 标题、地点与备注 | 标题 / 时间 / 位置 / 备注 | 可包含地点、备注及其中的他人信息 |

> 图片在本地生成，由用户决定是否分享。明确启用共享日历后，应用把允许的输出字段写入用户选择的日历账户，由该服务提供商同步（iCloud 由 Apple 处理）。本地只保存偏好、共享配置、覆盖、状态和身份映射，不额外持久化完整来源日程数据库。详见[隐私政策](隐私政策.md)。

## 运行要求
- **iOS**：17.0+；共享功能需要启用 iCloud 日历。
- **Xcode**：需支持工程使用的同步文件组与应用图标资源；权限和工程配置使用 Xcode 27 检查。
- **依赖框架**：SwiftUI / EventKit / UIKit / SafariServices / BackgroundTasks。

Debug／Release 默认 `CHRONOGRAPH_APPLE_SIGN_IN = NO`，不请求 Apple 登录 entitlement，可使用免费 Personal Team 运行本机功能。账号密码登录与云端协作在此模式下可用。已有 Apple 登录凭据会保留，仅在开启 Apple 登录的构建中恢复。系统日历中的 iCloud 账户通过 EventKit 使用，不依赖此开关。

注册路径：设置 → 云端协作 →「有邀请码？创建账号」，填写管理员提供的邀请码、用户名（3至32位英文字母、数字、点、下划线或短横线）和密码（12至128个字符）。注册成功后仍需单独选择允许上传的日历。密码只通过 HTTPS 发送，应用不保存密码，钥匙串保存会话令牌。登录后可「修改密码」，其他设备的会话随即失效。忘记密码需联系服务器管理员，当前没有邮件找回服务。

以后需要启用云端 Apple 登录时，在应用 Target 的 Signing & Capabilities 选择付费团队，为相同 Bundle ID 启用 Sign in with Apple 并更新描述文件，再将应用 Target → Build Settings → User-Defined 中的 `CHRONOGRAPH_APPLE_SIGN_IN` 设为 `YES`（Debug／Release 分别设置，或命令行传入 `CHRONOGRAPH_APPLE_SIGN_IN=YES`）。该开关同时选择 `Config/ChronoGraph.entitlements` 并开启登录界面。

### 权限描述 (Info.plist)
Debug 和 Release 均将 `Config/ChronoGraph-Info.plist` 与生成的应用元数据合并，包含 `NSCalendarsFullAccessUsageDescription` 和兼容键 `NSCalendarsUsageDescription`，说明预览、图片与主动启用后的脱敏 iCloud 写入。源 plist 提供 `UIBackgroundModes = [fetch]` 和 `BGTaskSchedulerPermittedIdentifiers = [com.shiyao-zhang.ChronoGraph.shared-calendar-refresh]`，任务标识必须与应用注册一致。

## 快速开始
1. 克隆仓库。
2. 打开 `ChronoGraph.xcodeproj`。
3. 在目标设置里配置 Team（签名）；应用通过 EventKit 使用设备已有的 iCloud 账户，不使用 CloudKit 容器。
4. 选择真机 / 模拟器运行，首次访问会弹授权框。
5. 选择日历并调整本机查看 → 分享图片 → 检查预览 → 发送图片。维护订阅日历时，先创建草稿并审阅确认共享规则。

## 错误与安全处理
- 事件抓取使用 UUID Token 避免竞态（后发覆盖先发）。
- 渲染尺寸上限防止 CoreGraphics 内存/尺寸崩溃。
- 双路径渲染降低空白图风险。
- 失败不强制自动分享（需非空图像）。
